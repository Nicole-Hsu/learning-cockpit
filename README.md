# 課堂應答器

教室即時作答系統，老師發布題目（大題可拆多個小題，可含文字/圖片，四選一 A-D），學生掃 QR code、輸入班級代碼 + 座號登入作答。大題限時，逾時未答算 timeout；課後統計每位學生的答對數與作答耗時排名。同科別的題庫可以跨班級共用，但各班的作答資料嚴格隔離，互不可見。學生的登入作答動作本身兼作點名，不需要額外的點名介面。

## 狀態
規劃中，資料模型與權限模型已定案（見 `CLAUDE.md`），尚未開始寫程式碼。

## 技術路線
純前端（HTML/CSS/JS，vanilla JS，不用建置工具）+ Firebase（Firestore 即時同步 + Google 登入白名單），部署於 GitHub Pages。介面風格參考同作者的 `kj-affinity-board` 課堂便利貼工具。

## 隱私
學生資料一律去識別化，只用座號 + 班級代號，不存真實姓名或學號。
