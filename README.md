# Learning Cockpit

課堂互動工具套件。每個工具放在 `tools/<工具名>/`，各自獨立運作、獨立資料，共用同一套視覺風格（沿用 KJ 便利貼牆的橘色圓角卡片風格）。

## 工具清單
- **課堂應答器**（開發中）：教室即時作答系統，老師發布題目（可含小題、圖片、四選一 A-D），學生掃 QR code、用座號登入作答；大題限時，逾時算 timeout；課後統計答對數與作答耗時排名。同科別題庫可跨班共用，各班作答資料互不可見。
- **KJ 便利貼牆**（規劃中，尚未搬入）：目前仍獨立在 `2026-KJ分類法` repo，已上線使用中；等課堂應答器完成後再規劃安全搬遷。

## 技術路線
純前端（HTML/CSS/JS，vanilla JS，不用建置工具）+ Firebase（Firestore 即時同步 + Google 登入白名單），部署於 GitHub Pages。

## 隱私
學生資料一律去識別化，只用座號 + 班級代號，不存真實姓名或學號。
